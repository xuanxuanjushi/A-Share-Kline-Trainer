大A日K股票模拟训练器 V17 使用说明

一、本版重点

- 板块列表和成分股行情增加统一缓存，第一次打开软件时会提前准备，之后进入板块和切换分类会明显更快。
- 首次启动会显示加载动画，并随机展示一条投资语录，只显示“语录 + 说话人”；内容包含投资哲学、风控、短线心法、游资语录和幽默段子。
- 板块页面修复菜单、缩放和标题显示：K线缩放范围与个股页一致，标题改为单行，名称和代码加粗放大。
- 帮助菜单的稳定性问题已修复。

二、直接运行

- 源码模式：双击项目根目录的“运行.bat”。
- 便携版：解压后双击“运行.bat”或同目录的 EXE，不需要安装 Python、PySide6 等依赖。
- 便携版第一次打开会准备行情缓存，所以会比之后启动稍慢；这是正常现象。

三、首次启动与开屏界面

- 第一次启动会自动预热板块目录和全市场股票行情，完成后主窗口才会显示。
- 加载期间会显示移动渐变条和随机投资语录，避免白屏等待。
- 以后启动会优先使用已有缓存，速度更快；后台仍会检查行情是否有更新。
- 如果通达信行情刚更新，第一次进入板块可能重新计算相关缓存。

四、板块选股训练

- 顶部“板块选股训练 / 个股训练”用于切换页面。
- 板块页支持一级行业、二级行业、概念、风格分类，以及名称、代码、首字母搜索。
- 首次进入板块页会默认选中第一个板块，避免界面空白；点击其他板块后加载对应成分股和走势。
- 点击板块列表空白处或主图空白区域不会取消当前选择，只会清除表格的虚线焦点框。
- 单击成分股预览K线，双击或点击“进入个股训练”开始训练。
- 模拟日期输入框固定为选定的日期，平移/缩放窗口不会自动改动它。
- “返回模拟日期”按钮用于回到宿主当前模拟日期；按钮始终可点，已经在模拟日期时会重新加载并提示。
- 板块表和成分股表只显示至少有一个有效行情数字的标的；没有有效行情的行不显示。
- 板块表和成分股表最前面都有“序号”列，按当前排序结果从 1 开始编号。
- 板块表和成分股表列宽会按当前窗口宽度自动均分；窗口缩放后重新适配，尽量在常见分辨率下完整显示。
- 表格行高、表头内边距和列间距已收紧，整体更紧凑。
- 成分股标题会加粗显示“所属板块：板块名称”，并保留成分股数量。
- 行业板块和成分股表都显示量比；量比按日K成交量计算：当日成交量 ÷ 前5个交易日平均成交量，开盘阶段使用上一完整交易日。
- 成分股表显示现价、涨幅、开盘竞价涨幅、5/10/20日涨幅、当日及5/10/20/60日换手率、成交额、量比和所属行业。
- 成分股表在20日涨幅后显示“近一年涨幅”，按250个交易日前的收盘价计算；历史不足时显示横线。
- 成分股名称后面的上角标数字表示连板数，例如 2 表示连续两个交易日涨停；只有首板不显示角标。
- 风格分类里额外提供程序自行统计的三个“今日”清单：今日涨停、今日连板、今日跌停，按本地最新交易日计算，不随模拟日期变化；这三个清单没有指数日线，只列出成分股。
- 涨停/跌停判断按板块幅度：主板与 ST 10%、科创板/创业板 20%、北交所 30%，并允许价格取整带来的零点几个百分点偏差。
- 板块表和成分股表选中一行后，除了上下方向键，也可以按回车键向下切换。
- 双击“一级行业 / 二级行业 / 概念 / 风格”这几个标签，会把板块列表强制拉回顶部；点击任何表头排序后也会自动回到顶部，方便直接看到排在最前面的结果。
- 点击板块表或成分股表最左边的“序号”可以收藏（序号变成金色角标），再点一次取消；收藏的标的始终排在最前面，并会随“文件 → 保存当前配置”一起保存，退出重开仍保留。
- 风格分类里还提供“近半月腰斩 / 近一月腰斩 / 近三月腰斩”：按区间最高收盘价到最新收盘价的跌幅计算，跌 40%~60% 的个股列入（统计窗口约 15 / 25 / 70 个交易日，比自然半月、一月、三月略宽松）；跌幅不到 40% 或超过 60% 的不列入。
- 切换板块或个股时，K 线的缩放（显示多少根）保持不变，只把显示位置回到最新；刚上市等历史不足的股票会保持正常K线宽度并靠右显示，不会被横向拉伸。
- 所属行业有二级行业时显示“一级行业 › 二级行业”，只有一级行业时显示一级行业。
- 板块浏览和随机日期不再受个股或大盘当前训练日期限制，可在本地有效历史内自由切换，不弹训练日期错误。
- 随机日期每次相互独立，未选择任何板块也可以随机。
- 随机范围为“所选板块起始K线 → 最近行情往前推 N 根”，N 取“模拟 → 随机训练时长”的设置；未选板块时使用大盘日历。
- “最近 / 最早 / 手动输入日期”不受随机训练时长限制，未选择板块时点击“最近”会回到本地最新行情。
- 随机日期按“年 → 月 → 日”分别随机，再落到该范围内实际存在的交易日。
- 随机或跳转日期前会清除当前个股选择；如果随机到的新日期没有原板块行情，该板块不会继续显示。
- 板块图支持方向键平移、Ctrl+滚轮或按钮缩放，右键菜单可增减副图。
- 板块图默认显示 70 根K线；自动选板块时优先选择本地K线至少 70 根的板块，如果都不够则选择K线最多的板块。
- 板块图标题显示为“名称 代码 起始日期 至 结束日期 共X根K线”，名称和代码更醒目。

五、本地数据与缓存

- 普通 EXE 模式数据目录：%APPDATA%\大A日K股票模拟训练器
- 源码模式数据目录：项目 config 文件夹
- 便携模式数据目录：程序旁的 portable_data 文件夹
- 必要配置：settings.json（数据源、初始资金、复权方式、界面偏好等）。
- 用户记录：session_state.json（续作会话）、performance_history.json（历史成绩），请勿随意删除。
- 可重建缓存：sector_cache、adjusted_bars_cache、gbbq_events、market_stats_daily.json、shanghai_index_daily.json。
- 清理可重建缓存后，第一次打开或进入板块会重新生成，可能需要等待；训练记录不会因此丢失。

六、备份与迁移

- “文件 → 保存当前配置”会保存窗口大小、最大化状态、主分隔条、板块页分隔条、表格列宽、板块图副图数量/类型/高度和图表窗口大小，下次启动自动恢复。
- 文件 → 数据备份与迁移 → 导出轻量数据备份（ZIP）：保存设置、续作会话和历史成绩。
- 文件 → 数据备份与迁移 → 生成免安装便携版：生成可拷贝到另一台 Windows 电脑直接运行的文件夹。
- 便携版可以选择包含当前行情数据；包含行情的版本会同时带上板块指数日K和行业、概念、风格名单，复制和首次启动会需要一些时间。

七、常用快捷键

- Ctrl+F 或 Tab：切换全屏模式；Esc：退出全屏模式。
- R：随机换股或随机定位交易日期（输入框内输入不受影响）。
- 方向键：平移K线；Ctrl+方向键或 Ctrl+滚轮：缩放。
- B / S：买入 / 卖出。
- Home / Ctrl+→：回到最新K线；End / Ctrl+←：跳到最早K线。
- 快速双击空格：开关指数或板块指数叠加。
