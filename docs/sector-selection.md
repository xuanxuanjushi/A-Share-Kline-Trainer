# 板块选股（日 K）设计与实施记录

用户已确认双入口方案，范围仅日 K；行业页保留一级、二级标签和父级归属。2026-09-13 按最新要求移除三级标签；个股页切换栏移入左侧图表顶部，避免挤压右侧交易区，时间使用微软雅黑字体。沿用 PySide6，不新增依赖或网络服务。

## 模块与接口

- `stock_simulator/sectors/service.py`：只读通达信行业、当前成员和日线，输出截止日期快照；不访问账户。
- `stock_simulator/sectors/page.py`：左行业、右上日 K、右下股票，后台读取、数字排序、搜索、历史缩放平移。
- `stock_simulator/sectors/contracts.py`：不可变日期上下文与训练请求，公共接口约定。
- `stock_simulator/sector_integration.py`：桌面本地 API 适配层，连接旧训练宿主与新页面。进程内接口调用，不开 HTTP 端口。
- `stock_simulator/app.py`：仅增加适配层安装、刷新通知与板块页快捷键隔离。

## 状态约定

切换页面不改变账户、持仓、交易与原图表。正式训练共用引擎日期和开收盘阶段；开盘日线只提供开盘价格，高低收以开盘价替代，成交量额归零，收盘涨幅暂不提供。浏览时可独立选择日期，进入训练后同步。板块页推进正式训练时调用原行情推进入口。

当前行业归属不是历史归属，始终可见标识。使用 TDX Txxxx / Txxxxxx / Txxxxxxxx 行业分类，归属按前缀匹配、显示完整路径；没有父节点的下级不展示，不混入概念指数。没有十年文件时展示实际可见起止日期，不填造数据。不复权日线的阶段涨幅跨除权可能跳变，界面说明。

进入训练请求包含股票、日期、开收盘阶段和数据源；适配层重新校验。已有持仓拒绝换成其他股票，选择同代码只返回原训练。连续模式沿用续作资金及归档入口，独立/单吊模式沿用原换股归档入口。收盘筛选后从该日收盘开始训练，禁止回到该日开盘成交。临时测试或可返回正式账户的浏览状态先返回原训练。进入板块取消此前待执行的随机/续作换股意图，保留纯预取缓存。

## 公共 API

- `SectorService(root).sectors(level=1, parent='')`：行业代码、名称、层级、父代码、完整路径。
- `sector_quotes(context, level=1, parent='')` / `member_quotes(sector_code, context)`：行情快照；缺失值使用 None，并返回原因。
- `history(code, context)`：仅截止日期可见的日 K，开盘遮蔽在服务层完成。
- `MarketContext(root, date, closed, locked=False)`：不可变上下文；date 为 ISO 日期，closed 为当天是否已揭示收盘。
- `TrainingRequest(code, context)`：不可变选股请求；由 `TrainingAPI.open_training()` 校验并提交。
- 页面 `training_requested` / `advance_requested` / `context_changed` 信号连接适配层；页面不读取主窗口内部对象。
- UI 后台任务携带 serial + cancel 标记；过期结果不渲染。服务缓存按行情文件大小与修改时间失效，上限 192 个品种。

## 使用

运行根目录“运行.bat”，配置通达信目录后点击顶部“板块选股训练”。浏览时选择日期；正式训练时锁定引擎日期并通过推进按钮揭示下一阶段。单击行业查看日K及成员，单击成员预览，双击或点击“进入个股训练”接入训练。返回板块保留未变化的页面选择与排序。左侧标签切换层级，下拉筛选上级；空层级显示原因。
